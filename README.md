# АИС «Гостиница» — учебный проект

Программное обеспечение автоматизированной информационной системы гостиницы.
Вариант 19, дисциплина «Основы программной инженерии», ГУАП, группа 4432.

## Назначение системы

* единый реестр номерного фонда с актуальным состоянием номеров;
* приём и подтверждение броней по всем каналам продаж;
* заселение и выселение гостей, ведение счёта;
* учёт дополнительных услуг и заданий на уборку;
* отчётность о загрузке и выручке.
