# Ролевая модель проекта (Redmine)

| Роль | Основные права |
|------|----------------|
| Руководитель проекта | все права: участники, версии, задачи, последовательности действий |
| Специалист по ИС | задачи, файлы, хранилище, wiki, категории |
| DevOps-инженер | задачи, файлы, управление хранилищем, связи задач |
| Системный программист | ведение и редактирование задач, фиксация в хранилище |
| Программист | создание задач, комментарии, учёт времени, фиксация в хранилище |
| Администратор БД | ведение задач по базе данных, учёт времени |
| Заказчик | просмотр задач, диаграммы Ганта, комментарии |
